GitHub-Native AI Documentation System

docs-as-code · static-first · AI-in-CI — the repo is the truth, the site is an artifact, AI writes only through PRs

Generation Plane

  • • AI runs only in CI jobs or the local CLI — never in the serving path
  • • Every job is bound to a named task contract with an output schema
  • • Thin provider abstraction: one interface, four adapters, config routing
  • • Change detection via source hashes regenerates only stale pages

Guarantees

  • • Generated content persists only through pull requests with human approval
  • • Deterministic validation first: lint, schema, links, Mermaid, build
  • • Untrusted-content boundary: repo text is data, never instructions
  • • Provenance frontmatter and per-source hashes on every generated page

Delivery Modes

  • • Mode B default: GitHub Pages deploy from Actions
  • • Mode A: identical artifact on any static host
  • • Mode C: offline or air-gapped local serving
  • • Build-time local search index works in every mode; Algolia optional in B
