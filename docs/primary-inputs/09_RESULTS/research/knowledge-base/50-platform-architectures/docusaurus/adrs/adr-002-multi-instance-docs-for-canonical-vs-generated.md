# ADR-002: Separate canonical and AI-generated content via docs-plugin multi-instance

## Status
Proposed (2026-08-12)

## Context
The ecosystem mandates that AI-derived views (recruiter pages, interview-prep sections, role-specific docs) be strictly separated from canonical documentation while going through the same build, validation, and PR review pipeline. `@docusaurus/plugin-content-docs` supports multiple independent instances distinguished by `options.id`, each with its own `path`, `routeBasePath`, sidebars, and per-instance CLI (`docs:version:<id>`) — see `packages/docusaurus-plugin-content-docs/src/index.ts` (pluginId handling) and the upstream dogfooding at `website/docusaurus.config.ts:369` (`id: 'community'`).

## Decision
Run at least two docs instances in `docusaurus.config.ts`:
- `docs` (default id): `path: 'docs'`, `routeBasePath: 'docs'` — canonical, human-authored.
- `generated`: `path: 'generated'`, `routeBasePath: 'views'` — AI-derived MDX only, written exclusively by the generation pipeline via PRs.

The AI pipeline never writes into `docs/`. Both instances get `onBrokenLinks`-equivalent enforcement via the site-level `throw` settings. Generated files carry provenance frontmatter (ADR-005). Sidebars for `generated` are autogenerated from directory structure plus `_category_.json` files so generators control IA deterministically (`packages/docusaurus-plugin-content-docs/src/sidebars/generator.ts`).

## Consequences
- Hard directory/route separation makes review policy, CODEOWNERS rules, and cleanup (regeneration can delete-and-rewrite the whole `generated/` tree) trivial and safe.
- Cross-instance links must use absolute site paths (resolved and checked by the broken-links checker at build).
- Slight config duplication (two plugin blocks, two sidebar files); acceptable.
- Additional derived-view families (e.g. per-role) can become further instances or subdirectories without redesign.

## Alternatives
- **Single docs instance, subdirectory convention:** weaker isolation; a generator bug can corrupt canonical sidebars; rejected.
- **Blog/pages plugins for derived views:** wrong IA model (chronological / unstructured); rejected.
- **Separate Docusaurus site for generated content:** doubles operations and breaks unified search/navigation; rejected for one-engineer constraint.
