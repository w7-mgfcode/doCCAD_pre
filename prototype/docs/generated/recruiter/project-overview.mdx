**DOCCAD** is an evidence-backed documentation platform built on docs-as-code principles. It decouples human-authored engineering truth (`/docs`) from audience-specific AI views (`/views`), deploying as a high-performance static website with zero runtime AI costs, latency, or single points of failure.

## 2. Two-Minute Technical Walkthrough

Engineering teams face a dilemma: documentation is either painfully outdated or unreliably generated by opaque AI tools. DOCCAD solves this through architectural discipline:

1. **Human-Owned System of Record**: Engineers maintain canonical Markdown files and Mermaid diagrams in Git. No external CMS, vector database, or dynamic backend exists (<EvidenceLink to="/docs/decisions/adr-001-github-source-of-truth">ADR-001</EvidenceLink>).
2. **Offline AI Generation Plane**: CLI and CI pipelines invoke a thin provider abstraction to generate audience-focused views. Prompts assemble evidence strictly via Level-1 deterministic file selection (<EvidenceLink to="/docs/decisions/adr-006-retrieval-level1">ADR-006</EvidenceLink>).
3. **PR-Gated Governance**: Generated artifacts persist only through pull requests on `docs-gen/*` branches, subject to deterministic validation gates (<EvidenceLink to="/docs/decisions/adr-005-pr-gated-generation">ADR-005</EvidenceLink>).
