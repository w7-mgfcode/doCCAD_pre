# Question: How does DOCCAD ensure AI-generated content does not pollute canonical documentation?

## Grounded Answer

DOCCAD enforces physical separation through two independent `@docusaurus/plugin-content-docs` instances (`/docs` for human canon vs `/views` for generated views). Canonical docs are human-owned and never cite generated content, preventing hallucination loops.
