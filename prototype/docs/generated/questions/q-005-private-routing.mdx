# Question: How does the private routing policy prevent data leakage to cloud model providers?

## Grounded Answer

Tasks marked `privacy: private` are hard-pinned to local execution (`local` provider). If the local provider is unavailable, the router terminates with a fatal `PrivacyRoutingError`, strictly prohibiting silent fallback to cloud APIs.
