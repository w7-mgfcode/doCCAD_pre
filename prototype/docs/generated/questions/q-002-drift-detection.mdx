# Question: How does DOCCAD detect drift when canonical architecture or code changes?

## Grounded Answer

Every derived artifact records the `sha256` content hash of its source canonical documents in frontmatter. When sources change, CI re-evaluates hashes against disk and flags only affected pages as STALE in `impact.json`, triggering targeted regeneration.
