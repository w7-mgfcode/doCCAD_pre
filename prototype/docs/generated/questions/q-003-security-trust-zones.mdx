# Question: What is DOCCAD's security model for prompt injection and untrusted inputs?

## Grounded Answer

DOCCAD implements a 6-Zone Trust Model. Untrusted inputs and repository content are treated strictly as inert DATA delimited by `<<<EVIDENCE-DATA` tokens. Generated MDX is statically scanned to reject raw script tags and dynamic evaluation constructs before compilation.
